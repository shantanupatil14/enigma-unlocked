# Making the reel

The reel is generated by code from the website's own files, so it can be re-made at any time.

## One-time setup (Windows, PowerShell, from this folder)
```
python -m venv .venv
.\.venv\Scripts\pip.exe install -r requirements.txt
```
Needs the Microsoft Edge browser (already on Windows). ffmpeg comes bundled inside `imageio-ffmpeg`.

## Build
```
.\.venv\Scripts\python.exe build_reel.py all both        # story cut + short cut: narration, frames, MP4 files
.\.venv\Scripts\python.exe build_reel.py all story       # just the ~87 s cut
.\.venv\Scripts\python.exe build_reel.py render story --range 50 62   # frames for a 12 s preview
.\.venv\Scripts\python.exe contact.py story 120                      # contact sheet of frames to check by eye
```
Results go to `out/` (four MP4 files: story and short, each in high quality and in a WhatsApp-size version under 15 MB).

## How it works
- `script.json`: the narration and what is on screen when (anchored to spoken words), for both cuts.
- `build_reel.py`: speaks the narration with edge-tts (voice en-GB-RyanNeural, +5% rate, needs internet; the audio is cached in `work/`), reads the word timings, builds a timeline, then renders `reel.html` frame by frame in Edge on a frozen, manually stepped clock so the pictures always match the voice, and encodes with ffmpeg.
- `reel.html` / `reel.js`: the 1080x1920 page. It reuses the website's `enigma.js`, `store.js`, `inside3d.js` and `characters.js`.
- Change the phrase, the machine settings, the voice or the wording in `script.json`, then rebuild.
