About this project

Enigma Unlocked is a free, educational website that shows how the Enigma cipher machine works, then lets you play with a working one.

How to use it

  • Story: a short sketched tale about a secret message and the person trying to read it.
  • Learn: seven short chapters, each with a scene and something to try.
  • Machine: a 3D view of the whole machine that plays your message letter by letter, plus a simple view with the classic keyboard and lamps.
  • Code Library: real messages to decode, with exact settings and answers that are tested against the machine.

What is and is not simulated

The machine here is the three-rotor Army model (often called Enigma I): rotors I to V, mirror plates A, B and C, a ten-cable plugboard, ring settings and the middle-rotor double step. It reproduces the standard published test result (rotors I, II, III with every dial on A turns AAAAA into BDZGO). The rotor and mirror tables are published historical facts; the project checks that each table is a valid permutation or pairing, but only the I, II, III with mirror B setup is checked against a known historical result. Other models (the naval four-rotor machines, for example) are not included.

Please note

  • This is a teaching toy. It is not a security tool. Enigma was broken during the Second World War, and you should never use it to protect anything real.
  • Anna and Tom are invented characters, and all drawings and text were created for this project. The project is not affiliated with, or endorsed by, any museum, film, company or organisation.
  • The site works offline and does not collect any data. Nothing you type leaves your browser.
